# KageriEditor（Windows版）

小説・原稿を書くための、Windows用のテキストエディタです。

縦に長い原稿でも軽く、日本語入力を邪魔しないことを大切にしています。原稿はふつうのテキストファイル（.txt・.md）として保存されるので、このアプリをやめても、そのまま他のソフトで開けます。

## ダウンロード

右側の「**Releases**」から、最新版の `KageriEditor-1.1-setup.exe` をダウンロードしてください。

## 入れ方

1. ダウンロードした `KageriEditor-1.1-setup.exe` をダブルクリックします。
2. 「WindowsによってPCが保護されました」という青い画面が出たら、「**詳細情報**」→「**実行**」を押してください。作者の署名が付いていないため出る警告です。
3. 画面にしたがって進めてください。**管理者の許可は要りません。**
   - 入れ場所は `C:\Users\（あなたの名前）\AppData\Local\Programs\KageriEditor` です。
   - スタートメニューに登録されます。デスクトップのショートカットは、希望すれば作られます。
   - `.txt`・`.md`・`.log` を右クリックしたときの「プログラムから開く」に、このアプリが並びます。
4. 初めて起動したときは、原稿を保存するフォルダを尋ねます。決めると「3分でわかるチュートリアル」が開きます。

ダブルクリックでこのアプリが開くようにしたいときは、設定（Ctrl+I）の「ファイルの関連付け」から Windows の「既定のアプリ」を開いて選んでください。Windows の決まりで、アプリの側からは変えられません。

## 動かすもの

- Windows 11／Windows 10（64ビット）
- ほかのソフトを入れる必要はありません。

## おもな機能

- 長い原稿（数万字以上）でも、改行やスクロールが引っかからない本文
- タブで複数の原稿を開ける
- 改行（↩）・全角スペース（□）を印で見せる
- 行番号と、文字数の目盛り
- 自動保存、保存の履歴
- 閲覧モード（Ctrl+B）と、Markdownの記法を整えて見せる表示（β）
- 見出しの印・目次・推敲の一覧
- 整形（字数での折り返し・空行や空白の除去など）
- 検索・置換、一覧表示
- 保存フォルダのすべての原稿から探す、全文検索（Ctrl+Shift+F）
- 書体・文字サイズ・行間・ダークモードの設定
- 印刷

よく使うキー：Ctrl+S 保存／Ctrl+O 開く／Ctrl+F 検索／Ctrl+Shift+F 全文検索／Ctrl+B 閲覧モード／F1 使い方ガイド／Ctrl+/ ショートカット一覧

## 通信について

**このアプリは、インターネットに接続しません。** 原稿やその中身を外部へ送ることは一切なく、利用状況の記録（テレメトリ）も送らず、更新の確認もしません。広告もアカウント登録もありません。

（保存フォルダにDropboxやOneDriveなどの同期フォルダを選んだ場合は、そちらのソフトが同期します。このアプリの働きではありません。）

## 設定の置き場所・やめるとき

- 設定は `C:\Users\（あなたの名前）\AppData\Roaming\KageriEditor\settings.json` に保存されます。
- やめるときは、Windowsの「設定」→「アプリ」から KageriEditor をアンインストールしてください。**原稿と設定は消えません。** 設定も消したいときは、上の `KageriEditor` フォルダを削除してください。
- 新しい版は、そのまま上から入れられます。
